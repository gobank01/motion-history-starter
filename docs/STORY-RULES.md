# กฎเล่าเรื่อง (ใช้กับทุกบท)

อาการที่ต้องเลี่ยง: บทเป็นข้อเท็จจริงเรียงต่อกันแบบหัวข้อข่าว ("{7:02} เรดาร์บนเกาะ" "สองระลอก รวม{353 ลำ}") มีตัวเลขเยอะ
แต่ไม่มีตัวเอก ไม่มีเหตุว่า "ทำไม" และแต่ละประโยคไม่ต่อกัน คนดูได้ข้อมูลแต่ไม่ได้เรื่อง

## 1 คลิป = 1 เรื่องเล่า
1. **คำถามเดียว** เขียนไว้บนสุดของบท ทุกบรรทัดต้องพาไปหาคำตอบ บรรทัดที่ตัดได้โดยเรื่องไม่เสีย = ตัด
2. **ตัวเอกมีเป้าหมาย + เดิมพัน** คน/กลุ่มจริงที่ "อยากได้อะไร" และ "จะเสียอะไรถ้าพลาด" (พลทหารเรดาร์, ชาวบ้านค่าย, พ่อค้า)
3. **ที่มาที่ไปก่อน** ภายใน 15 วิแรกต้องตอบว่า "ทำไมเรื่องนี้ถึงเกิด" (เหตุจูงใจ ความจำเป็น ความขัดแย้ง)
4. **เชื่อมด้วย "แต่ / เลย / เพราะ / จน"** ห้ามเรียงแบบ "แล้วก็" — อ่านบทออกเสียงแล้วใส่คำเชื่อมระหว่างทุกบรรทัดได้
5. **โครง (spine)**: ตอนนั้น… → ปัญหาคือ… → เลยตัดสินใจ… → แต่… → จนวันหนึ่ง… → ผลที่ไม่มีใครคาด… → ทุกวันนี้/ประโยคปิดที่พลิกฮุก
6. **ปมกลางเรื่อง (~35–45%)** "แต่มีสิ่งหนึ่งที่ไม่มีใครรู้…" ให้คนดูอยู่ต่อหลังเฉลยแรก
7. **พากย์เป็นประโยคเต็ม แบบเล่าให้เพื่อนฟัง** ใช้ "ลองนึกภาพ" "เชื่อไหมว่า" ประโยคพูดจริงในประวัติศาสตร์ (ถ้ามีหลักฐาน) รายละเอียดที่เห็นภาพ ซับ = คำพากย์
8. **ตัวเลขน้อยลง** ตัวเลขยักษ์/การ์ด ≤ 4 ต่อคลิป เลือกเฉพาะตัวที่ขับเรื่อง ที่เหลือพูดเป็นภาษาคน
9. **ป้ายบท = ช่วงของเรื่อง** ไม่เกิน 3 บท ชื่อบทเป็นจังหวะเรื่อง ("ทางตัน" "แผนเสี่ยง" "ผลที่ไม่มีใครคาด") ไม่ใช่หัวข้อ
10. **ปิดแบบพลิกฮุก + ต่อเนื่องข้ามตอน** ประโยคปิดทำให้ฮุกมีความหมายใหม่ แล้วโยงไปตอนถัดไปในซีรีส์ 1 บรรทัด ("ตอนหน้า: …" บน outro) — จัดลำดับตอนให้ต่อกันได้ (เหตุการณ์เดียวกันคนละมุม / ยุคเดียวกัน)
11. การ์ดสรุปท้ายใช้เมื่อเรื่องเป็นบทเรียนจริงเท่านั้น ไม่บังคับ

ข้อเท็จจริงยังเข้มเหมือนเดิม (ตรวจ 2 รอบ ตำนาน = "เล่ากันว่า" ตัวเลขไม่นิ่ง = "ราว")
